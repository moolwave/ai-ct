# ai ct

발주처가 납품받은 AI 챗봇을 검수하는 도구입니다. 질문셋으로 답을 대조하고, 사람이 판정한 결과만 확인서의 결론으로 적습니다. 자동 검사에 걸린 상태는 오류 확정이 아니고, 사람이 보지 않은 문항은 통과가 아닙니다.

확인서는 인증이 아닙니다. 답변 파일의 SHA-256에서 시작해 판정 이벤트를 해시로 잇고, 확인서에 마지막 해시를 남깁니다.

## 실행

```bash
npm install
npm test
npm run dev
```

브라우저에서 [http://127.0.0.1:43123](http://127.0.0.1:43123) 을 엽니다. 기본으로 이 컴퓨터에서만 접속됩니다.

### 다른 기기에서 쓰기 (같은 네트워크)

접근 토큰 없이 네트워크에 열면 누구나 판정을 바꾸거나 검수를 지울 수 있습니다. 반드시 토큰을 정하고 엽니다.

```bash
AICT_ACCESS_TOKEN='12자 이상의 긴 문자열' npm run dev:lan     # 개발
npm run build && AICT_ACCESS_TOKEN='...' npm run start:lan   # 운영
```

- 토큰은 코드나 저장소에 적지 말고 환경 변수로만 넘깁니다. 바꾸면 모든 로그인이 풀립니다.
- 로그인은 12시간 유지됩니다. HTTPS 리버스 프록시 뒤에서는 쿠키가 Secure로 나갑니다(`AICT_SECURE_COOKIE=1`로 강제 가능).

처음 실행하면 한빛커머스 상담 챗봇 예시가 들어 있습니다. 환불 금액, 없는 보상 규정, 주민번호 출력, 고지 누락, 기준이 충돌하는 교환 기간, 납품사에게 보여 주지 않는 홀드아웃, 아직 판정하지 않은 문항이 섞여 있습니다. 예시 답변은 납품사가 제출한 파일이라고 선언돼 있어서, 확인서도 그 한계를 그대로 적습니다.

데이터는 `data/store.json`에만 있습니다. 외부 API 키는 필요 없습니다. `data/`는 git에 올리지 않습니다(답변에 개인정보가 있을 수 있음).

## 검수 순서

1. 새 검수에서 문서 종류를 고릅니다. 발주처 의뢰 확인서와 납품사 자체점검 리포트는 제목이 다릅니다.
2. 질문셋을 넣습니다. 기대 답변은 사람용 참고문이고, 자동 일치는 필수 표현·금지 표현·금액·날짜 슬롯만 합니다.
3. `question_id,answer` CSV를 가져옵니다. 파일 해시와 행 수가 기록되고 규칙 검사가 돌아갑니다. 나중에 문항을 추가했다면 답변 탭의 **빠진 문항 답변 추가**로 그 문항의 답만 붙입니다. 기존 판정은 그대로 남고, 추가 파일의 해시도 체인에 들어갑니다.
4. 작업대에서 정상, 오류, 판단 보류, 기준 불명 중 하나를 고릅니다. 오류에는 심각도가 필요합니다.
5. 확인서에서 중대 오류, 미검토, 홀드아웃 건수를 보고 해시를 확정합니다.
6. 해시 검증 화면에 그 해시를 붙여 같은 확정본인지 확인합니다.

예시 CSV는 `public/samples/hanbit-questions.csv`와 `public/samples/hanbit-answers.csv`입니다. `npm run seed`는 예시 저장소와 이 파일들을 다시 씁니다.

## 확인서가 말하는 것

- 중대 오류가 1건이라도 있고 모든 문항을 사람이 봤다면 결론은 납품 보류입니다. '중대 오류 시 납품 보류'를 꺼도 '중대 오류 없음'이 되지 않고 미결로 남습니다.
- 판정 체인이 깨졌으면(답변 본문이나 이력이 바뀜) 확인서를 확정하지 않습니다.
- 확정한 뒤 질문셋이 바뀌면 다시 확정하라고 표시합니다.
- 미검토가 남아 있으면 결론은 검수 미완료입니다. 지금까지의 중대 오류 건수는 따로 보여 줍니다.
- 판단 보류와 기준 불명은 통과율 분모에 넣지 않습니다.
- 홀드아웃 문항의 본문은 납품사용 수정 목록에 넣지 않습니다.
- 챗봇 API는 호출하지 않습니다. 수집 주체는 검수자가 파일에 대해 선언한 값입니다.

## 에러 로그

서버에서 난 오류는 `data/logs/errors.log`(JSON Lines, 1MB마다 회전)에 남고, 상단 메뉴 **에러 로그**(`/errors`)에서 스택까지 볼 수 있습니다. 화면에 "에러 로그 번호: err_…"나 digest가 보이면 그 값으로 찾습니다. 답변·질문 본문은 기록하지 않습니다.
